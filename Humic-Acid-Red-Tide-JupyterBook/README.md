# Humic Acid for Nutrient Reduction and Red Tide Mitigation — Jupyter Book

This folder is the complete Jupyter Book source for the project website. The navigation is intentionally compact:

1. Home
2. Study Areas
3. Research Program
4. Team
5. Project Outputs
6. Events & Field Gallery

**Home is intentionally concise:** it contains only the project summary and the overall project framework figure. The separate Project Overview, Quality/Data, and Progress pages have been removed. Task 1, Task 2, and Task 3 are presented within a single **Research Program** page as an illustrated, connected scale-up story. The task headings remain in the right-hand Contents panel rather than as nested items in the left navigation.


## Left navigation vs. right Contents panel

This book intentionally follows the same Jupyter Book layout as the earlier NBI project:

- `_toc.yml` controls the **left navigation** (the project pages).
- Markdown `##` and `###` headings inside each page automatically populate the **right-hand Contents panel**.
- Task 1, Task 2, and Task 3 are therefore headings inside `research_program.md`, not child pages in `_toc.yml`.

The right Contents panel is generated by Jupyter Book/Sphinx Book Theme during `jupyter-book build .`; it is not a separate page that must be maintained manually.

## Build locally

From the repository folder:

```powershell
conda activate nbi-book
jupyter-book clean .
jupyter-book build .
```

Then open:

```text
_build/html/index.html
```

If your current `nbi-book` environment does not have the required packages, create a separate environment:

```powershell
conda create -n ha-book python=3.11 -y
conda activate ha-book
pip install -r requirements.txt
```

## Publish from your local computer with `ghp-import`

Yes — you can publish this book the same way you publish a traditional Jupyter Book:

```powershell
jupyter-book clean .
jupyter-book build .
ghp-import -n -p -f _build/html
```

Run the commands **inside the local Git repository folder** after the repository has a GitHub `origin` remote. The `ghp-import` command builds/updates a `gh-pages` branch and pushes it.

In the GitHub repository, set:

**Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `gh-pages` → `/ (root)`**

If you use `ghp-import`, you do not need a GitHub Actions deployment workflow.

## Interactive study-area map

The Study Areas page uses **Leaflet** with **Esri World Imagery** as the default satellite basemap and OpenStreetMap as the street-map alternative. It does not require an API key. The map includes only two primary zoom buttons: **Experimental Site** (UF/IFAS SWFREC, Immokalee) and **Watershed Site** (Peace River watershed).

A Google Maps/Google satellite basemap can be substituted later, but a Google Maps JavaScript API key and appropriate domain restrictions/billing configuration would be required.

## Updating the team photographs

Replace the placeholder SVG files in `_static/img/team/` with approved images and update the corresponding paths in `team.md` if the file extensions change.

### Previous / next page links

The Jupyter Book theme is explicitly configured with `show_prev_next: true`, so each page in `_toc.yml` shows **Previous** and/or **Next** navigation links at the bottom, like the existing NBI project site. The order follows `_toc.yml`. Keyboard left/right navigation is also enabled.
