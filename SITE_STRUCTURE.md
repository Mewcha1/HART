# Site structure

The site uses the same three-part Jupyter Book layout as the earlier NBI project:

- **Left sidebar (Outlines):** Home and the main project pages, controlled by `_toc.yml`.
- **Center:** the selected page content.
- **Right sidebar (Contents):** automatically generated from `##` and `###` headings on the current page.

## Left navigation

1. Home
2. Study Areas
3. Research Program
4. Team
5. Project Outputs
6. Events & Field Gallery

Task 1, Task 2, and Task 3 are intentionally **not** separate left-navigation pages. They are section headings within Research Program, so they appear in the right-hand Contents panel.
